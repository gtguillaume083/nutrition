# La nutrition des êtres vivants

Application web libre pour la SVT au collège (5e, séquence « La nutrition des êtres vivants »).
Logiciel vibecodé avec Claude (Anthropic).

## Contenu

- **Parcours guidé** en quatre séances, chacune partant d'une énigme :
  1. la photosynthèse (Van Helmont, élodées d'Ingenhousz, cellule chlorophyllienne, équation) ;
  2. les réseaux trophiques (réseau à construire, producteurs, consommateurs, décomposeurs, recyclage de la matière) ;
  3. la respiration (graines germées en flacon fermé, eau de chaux, chêne de jour et de nuit) ;
  4. les mycorhizes (pépinière de pins, échanges champignon-racine, types d'associations, lichens).
  Chaque séance : Je découvre → J'expérimente → Je vérifie → Je retiens (bilan à compléter). Une trace écrite imprimable reprend tout.
- **Atelier** : quatre missions à refaire (réseau trophique, laboratoire des gaz, autotrophe ou hétérotrophe, défi bilan).
- **Espace enseignant** : un lien qui donne aux élèves le travail choisi (sans la partie enseignant), puis la lecture des codes de rendu en tableau.

Aucun compte, aucun cookie, aucun appel extérieur : la progression reste dans le navigateur de l'élève.
Le code de rendu est brouillé et contrôlé ; sans serveur, il n'est pas infalsifiable.

## Utilisation

Ouvrir `app/index.html` dans un navigateur, ou publier le dossier `app` (GitLab Pages : voir `.gitlab-ci.yml`).
